# BBL Mod Swapper

Turns an M-VAVE FM-1 into a Mod Swapper: a Teensy 4.1 runs open-source FM-1 firmwares (ported from the FM-1 Firmware Hub) and the FM-1 becomes its screen, keys and speaker. Swap firmwares from a menu, load samples and saves from an SD card.

- **Installer:** https://unkleblairy.github.io/BBL-MOD-SWAPPER/ (Chrome or Edge on a computer). Step 1 flashes the Teensy, step 2 installs the Mod Swapper terminal on the FM-1, and "Back to stock" returns the FM-1 to official V15.
- Release 1 is for Patreon members during its first week: the firmware files are in the Patreon post. They go up here after that week, with the source.

Not made or supported by M-VAVE or PJRC. GPL-3.0, no warranty. The installer's FM-1 update code is the Felucca web installer by Leo Kuroshita (Hügelton Instruments).
