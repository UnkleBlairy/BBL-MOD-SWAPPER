## Install

Download [JAMBOX.zip](JAMBOX.zip) (open it, press the download button), unzip it, and copy the `ROMS` folder to the top of your SD card. If the card already has a `ROMS` folder, let the files go into it.

You need all three files: `JAMBOX.R1`, `JAMBOX.R2` and `JAMBOX.R3`. Each one is the same firmware built for one of the Teensy's three flash slots.
